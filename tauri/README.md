# Game Goal на Tauri

Версия 2.0: та же программа, но вместо Electron — Tauri. Без установщика: один файл `GameGoal.exe` (6,5 МБ)
вместо 367 МБ рантайма Electron, и тот же код собирается под macOS и Linux.

## Установка и удаление

- Положи `GameGoal.exe` в любую папку и запусти. WebView2 уже есть в Windows 10/11.
- При каждом запуске программа сама кладёт ярлык в «Пуск» (без него Windows не показывает её уведомления),
  команду `gg` в `%LOCALAPPDATA%\Microsoft\WindowsApps` (эта папка уже в PATH) и включает автозапуск.
  Всё указывает на текущее место exe: перенёс файл — после запуска всё обновится.
- Каждое из этого выключается в настройках, вкладка «Виджет» → «В системе».
- Обновление: закрыть программу, заменить файл, запустить.
- Удаление: «Убрать из системы» на той же вкладке, потом удалить exe. Данные (`%APPDATA%\game-goal`) остаются.

## Как устроено

- Интерфейс общий с версией на Electron: `widget.html`, `settings.html`, `common.*`, `logic.js` из корня
  репозитория. `sync-web.mjs` собирает из них папку `web` и встраивает:
  - `shim/bridge.js` — то же `window.api`, что давал `preload.js`;
  - `shim/core.js` — бывший `main.js`: данные, достижения, скидки, курс ЦБ, трей, горячая клавиша.
    Работает в странице виджета, окно настроек обращается к нему сообщениями;
  - `shim/plugins.js` — JS-часть плагинов Tauri, собирается esbuild'ом.
- `src-tauri/src/main.rs` — тонкий слой над системой: один экземпляр (повторный запуск передаёт команду первому),
  плагины и файлы только внутри папки данных. `integration.rs` — ярлык в «Пуске» с AppUserModelID и команда `gg`.
- Данные — там же, где у версии на Electron: `%APPDATA%\game-goal`. `GAME_GOAL_PROFILE=<папка>` — отдельная
  папка для проверок.
- Без аппаратного ускорения (`--disable-gpu`): для пары окон оно не нужно, а GPU-процесс занимает ~90 МБ.

## Сборка

Нужны Rust (rustup, MSVC) и компилятор C++ из Visual Studio.

```bash
npm install
npm run build
```

Готовый файл: `src-tauri/target/release/GameGoal.exe`.

## Чем отличается от версии на Electron

- Нажатие на уведомление ничего не открывает: плагин уведомлений Tauri на компьютере не сообщает о нажатии.
- Автозапуск — через раздел Run в реестре, а не ярлык в «Автозагрузке».
- Нет записи в «Установке и удалении программ»: удаляется кнопкой в самой программе.

## Замеры (Windows 11, 2026-11-08)

Демо-данные, виджет висит 20 секунд без действий. Память — частная (private) по всем процессам программы.

| | Размер | Память с GPU | Память без GPU |
|---|---|---|---|
| Electron 44 | 367 МБ рантайма | 189 МБ | 113 МБ |
| Tauri 2 (WebView2) | 3 МБ exe | 200 МБ | 122 МБ |

По памяти Tauri на Windows не выигрывает: внутри у обоих Chromium. Выигрыш — размер и сборка под другие системы.
