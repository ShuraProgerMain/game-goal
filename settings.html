        Запускать вместе с Windows

        Звуки интерфейса
        Короткие сигналы на действия, без музыки

        В системе

        Программа — один файл без установки: . Ярлык, команда и автозапуск указывают на него. Если перенести файл в другую папку, при следующем запуске всё обновится само.
        Ярлык в «Пуске»
        Программу можно найти по названию. Без ярлыка Windows не показывает её уведомления.
        Команда gg в терминале
        gg add 1500 превью @Вася — добавить доход из любого терминала
        Версия
        Программа сама проверяет обновления раз в 12 часов
        Снимет ярлык, команду gg и автозапуск и закроет программу. Данные остаются, сам файл программы удали после этого.

        Резервные копии

        Копия данных сохраняется сама раз в день, хранятся последние 10. Перед восстановлением текущие данные тоже сохраняются в копию, так что его можно отменить.

          Скидки и курс

          Виджет двигается за любое пустое место. Правый клик по нему или по значку в трее открывает меню, двойной клик — эти настройки. Кнопка «−» прячет виджет в трей, вернуть его можно кликом по значку.
          В терминале: gg — показать виджет, gg add 1500 превью @Вася — добавить доход, gg stats — статистика, gg settings — настройки.
